# Sirf Tents

Working directory for Sirf Tents — a premium tent rental business in Brampton, Ontario serving the GTA South Asian wedding market. Used by the owner (Gurvir) to coordinate ad campaigns, lead handling, integrations, and copywriting with Claude Code. `CLAUDE.md` holds the permanent business rules; everything else evolves as work progresses.

## Contents

- **CLAUDE.md** — permanent business rules, brand constants, copy framework, and working style. Loaded automatically into every Claude session in this directory.
- **README.md** — this file. Orientation for what each top-level folder and file is for.
- **handoffs/** — long-form briefing docs for multi-step initiatives that span sessions (integrations, campaign launches, etc.). Each file is a self-contained handoff that picks up where the last session left off.
  - `hubspot-meta-integration.md` — open: bidirectional HubSpot ↔ Meta Ads sync to fix lead attribution.
